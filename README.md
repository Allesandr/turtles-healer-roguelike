# Черепахи и целитель — авто-рогалик

Автоматический рогалик с черепашками-ниндзя и целителем Аллесандром.

## Как играть

Откройте `index.html` в браузере (двойной клик или через локальный сервер).

Или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

и откройте http://localhost:8000

## Особенности

- Отряд: Аллесандр (целитель) + 4 черепахи (Лео, Дон, Майк, Раф)
- Автоматический бой
- Аугментации, экипировка, уровни
- Комнаты: бой, сокровищницы, привалы, боссы, паучьи логова
- Система ролей: танк, телохранитель, направляющий
